# @mandibula/clickable-area

Makes a container delegate safely to its primary link.

## Install

```sh
npm install @mandibula/clickable-area
```

## Use

```js
import "@mandibula/clickable-area";
```

```html
<mdb-clickable-area></mdb-clickable-area>
```

Registered elements: `<mdb-clickable-area>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
