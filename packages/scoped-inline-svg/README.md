# @mandibula/scoped-inline-svg

Fetches and safely scopes inline SVG identifiers.

## Install

```sh
npm install @mandibula/scoped-inline-svg
```

## Use

```js
import "@mandibula/scoped-inline-svg";
```

```html
<mdb-scoped-inline-svg></mdb-scoped-inline-svg>
```

Registered elements: `<mdb-scoped-inline-svg>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
