# @mandibula/modal

Programmatic accessible modal and its shared container.

## Install

```sh
npm install @mandibula/modal
```

## Use

```js
import "@mandibula/modal";
import "@mandibula/modal/styles.css";
```

```html
<mdb-modal-container></mdb-modal-container>
```

Registered elements: `<mdb-modal-container>`, `<mdb-modal>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
