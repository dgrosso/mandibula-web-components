# @mandibula/carousel

Responsive, accessible carousel controller for light-DOM content.

## Install

```sh
npm install @mandibula/carousel
```

## Use

```js
import "@mandibula/carousel";
import "@mandibula/carousel/styles.css";
```

```html
<mdb-carousel></mdb-carousel>
```

Registered elements: `<mdb-carousel>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
