# @mandibula/document-preview-button

Trigger and modal document preview.

## Install

```sh
npm install @mandibula/document-preview-button
```

## Use

```js
import "@mandibula/document-preview-button";
import "@mandibula/document-preview-button/styles.css";
```

```html
<mdb-document-preview-button></mdb-document-preview-button>
```

Registered elements: `<mdb-document-preview-button>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
