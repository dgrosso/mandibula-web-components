# @mandibula/post-loop

Fetch-driven post listing, filters, and pagination.

## Install

```sh
npm install @mandibula/post-loop
```

## Use

```js
import "@mandibula/post-loop";
```

```html
<mdb-post-loop></mdb-post-loop>
```

Registered elements: `<mdb-post-loop>`, `<mdb-post-loop-filters>`, `<mdb-post-loop-pagination>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
