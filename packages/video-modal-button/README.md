# @mandibula/video-modal-button

Video trigger backed by the modal component.

## Install

```sh
npm install @mandibula/video-modal-button
```

## Use

```js
import "@mandibula/video-modal-button";
import "@mandibula/video-modal-button/styles.css";
```

```html
<mdb-video-modal-button></mdb-video-modal-button>
```

Registered elements: `<mdb-video-modal-button>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
