# @mandibula/accessible-menu

Accessible disclosure navigation for authored menu markup.

## Install

```sh
npm install @mandibula/accessible-menu
```

## Use

```js
import "@mandibula/accessible-menu";
```

```html
<mdb-accessible-menu></mdb-accessible-menu>
```

Registered elements: `<mdb-accessible-menu>`.

The package is a standards-based custom element. It works in plain HTML, React 19+, Vue, Svelte, Angular, and other platforms that support custom elements. See the repository interoperability guide for framework event and property examples.
