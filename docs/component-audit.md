# Component implementation and accessibility audit

Audit date: 2026-08-03. Criteria: semantic HTML first, keyboard and focus behavior, accessible names, reduced motion, media alternatives, progressive enhancement, SSR imports, package isolation, and the current Modern Web Guidance recommendations.

| Package                   | Result                              | Notes                                                                                                                                                                                                                                                                                       |
| ------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `accessible-menu`         | Current                             | Uses authored buttons and ARIA disclosure state. Escape now closes the active submenu and restores focus. It intentionally does not implement a full application-menu arrow-key pattern.                                                                                                    |
| `carousel`                | Current                             | Native horizontal scrolling and scroll snap are appropriate. Scroll-driven visual effects must remain optional behind feature detection because Firefox lacks support.                                                                                                                      |
| `clickable-area`          | Current                             | Keeps the real link in the tab order and ignores nested controls. Do not add `role=link` to the host.                                                                                                                                                                                       |
| `collapsible`             | Current with scope caveat           | It is a region animation primitive, not a complete disclosure. Consumers own the trigger, accessible name, and `aria-expanded`/`aria-controls` relationship.                                                                                                                                |
| `counter`                 | Current                             | IntersectionObserver avoids off-screen work. Reduced-motion and zero-duration modes now render the final value immediately. Do not use a live region for decorative metric animation.                                                                                                       |
| `document-preview-button` | Current                             | Authored trigger, labelled modal, lazy iframe, and configurable sandbox. External documents still require a trustworthy embed policy and meaningful title.                                                                                                                                  |
| `fader`                   | Current                             | Provides keyboard navigation, carousel labelling, change events, and reduced-motion timing. Avoid automatic rotation without pause controls.                                                                                                                                                |
| `media-slot`              | Current                             | Dimensions/aspect ratio, alt handling, suspense, sanitized SVG, and muted autoplay behavior are appropriate. The `background` option should normally use empty alt because it is decorative.                                                                                                |
| `modal`                   | Legacy; replace in next major       | The public `mdb-modal` API is usable, but `mdb-modal-container` plus its manual focus trap is obsolete relative to native `<dialog>.showModal()`. Do not extend this architecture; migrate while preserving open/close events and focus restoration.                                        |
| `pagination`              | Current                             | Buttons keep native semantics, the indicator group no longer overwrites button roles, and empty indicator templates receive page labels.                                                                                                                                                    |
| `paper`                   | Current, decorative                 | Procedural visual surface is valid progressive enhancement. Content remains light DOM and must retain sufficient contrast independently of the generated edge.                                                                                                                              |
| `pointer`                 | Optional enhancement                | Not technically obsolete, but custom pointer decoration is non-essential and should not be a product dependency. It is disabled for coarse pointers and reduced motion. Never hide the native cursor or encode information only in the effect.                                              |
| `post-loop`               | Integration-oriented                | Fetch orchestration is valid, but WordPress endpoints/default action are platform-specific. Configurable `endpoint` and `terms-endpoint` now allow other backends. Consider moving WordPress defaults to an adapter package in the next major. Returned HTML is a trusted-backend contract. |
| `responsive-text`         | Transform mode deprecated candidate | `scaling="transform"` can reduce legibility and does not reflow text. Prefer CSS `clamp()`, container query units, wrapping, or the `font-size` mode. Consider defaulting to `font-size` and eventually removing transform mode.                                                            |
| `scoped-inline-svg`       | Current                             | Removes scripts, foreign content, event handlers, inline styles, unsafe protocols, and external references before insertion; IDs are scoped per instance. Same-origin/trusted assets remain preferable.                                                                                     |
| `spinner`                 | Current                             | Decorative motion respects reduced motion. Put it inside a named `role=status` region rather than applying an accessible name to an otherwise semantic-free custom element.                                                                                                                 |
| `suspense`                | Current                             | Delayed loader uses a polite status; failures use an alert; custom events bubble and cross shadow roots. Avoid noisy loading announcements for very short work.                                                                                                                             |
| `video`                   | Current with content obligations    | Native, YouTube, and Vimeo renderers have labelled frames. Native video supports caption tracks through `captions-*`; content owners must supply accurate captions/transcripts. Autoplay must remain muted.                                                                                 |
| `video-modal-button`      | Current API on legacy modal         | Trigger naming and lazy playback are appropriate. Its modal implementation inherits the native-dialog migration noted above.                                                                                                                                                                |

## Deprecation recommendations

1. Deprecate direct use of `mdb-modal-container`; rebuild `mdb-modal` on native `<dialog>` for the next major version.
2. Mark `responsive-text` `scaling="transform"` as deprecated and make `font-size` the next-major default.
3. Move WordPress-specific post-loop defaults into `@mandibula/wordpress-post-loop` or an adapter while keeping a generic endpoint contract in the core package.
4. Keep `pointer` as an optional visual package, not part of essential navigation or interaction guidance.

## Manual verification still required

- VoiceOver + Safari and NVDA + Firefox smoke tests for menu, fader, pagination, and modal.
- Keyboard-only walkthrough of every interactive demo.
- Real caption review for shipped media.
- 200% zoom and high-contrast review of consumer themes.
